# plan.md — 中間考査対策テスト自動生成スキル

## 背景

- 中学1年生の次男が1学期の中間考査を受ける
- 勉強スケジュールは既に立てた
- 試験範囲を覚えるための「小テスト形式の問題集」が欲しい

## やりたいこと

- 一回作って終わりではなく、**何度でもテストを生成できる仕組み**にしたい
- 試験範囲情報をコンテキストとして揃え、スキル化する
- 利用イメージ：「〇〇（教科名）のテストを作って」と頼むと、10〜20問程度のテスト問題が自動生成される

## 配布・利用形態（いずれか/複数）

- 印刷できる
- PDFで配布できる
- HTMLページとして GitHub リポジトリにプッシュし、GitHub Pages で閲覧できる

## 未確定事項（spec.md でユーザーに確認）

- 対象教科のリストアップ
- 試験範囲情報の入手方法・粒度（教科書ページ、ノート、配布プリント、デジタル化済みデータの有無）
- 問題形式（選択肢/穴埋め/記述/正誤など）
- 解答の付与方法（同一文書に答え合わせ欄、別解答用紙、HTMLで開閉式 など）
- 配布形態の優先順位
- スキル名
