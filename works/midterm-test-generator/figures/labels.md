# figures/labels.md — 理科の図の部位座標一覧

各 SVG 図に対し、ラベル番号マーカーやハイライト枠を上乗せする際の **基準座標** をまとめる。`make-test` skill が理科の図問題を生成する際に参照する。

座標は各図の `viewBox` 内の `x, y`（中心点）。`<circle cx="X" cy="Y" r="14" class="fig-marker"/>` と `<text x="X" y="Y" class="fig-num">N</text>` に流用する。

## マーカーの上乗せ方法（共通）

各図に番号を打つときは、上記座標に対して以下のペアを HTML 内に追加：

```html
<circle cx="X" cy="Y" r="14" class="fig-marker"/>
<text x="X" y="Y" class="fig-num">N</text>
```

`r="14"` の円が大きすぎて部位を覆ってしまう場合は、座標を**少しずらして横に置く**運用にする（例：「柱頭」を 200,110 ではなく 240,110 に置き、本来の柱頭位置に小さな矢印 or 引き出し線を加える）。
