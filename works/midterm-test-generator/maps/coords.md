# coords.md — 地図問題のマーカー座標参照テーブル

`make-test` スキルが社会の地図問題を作成するときに、`world-base.svg` のどの位置に番号マーカーや緯度経度ポイントを置くかの**唯一の参照テーブル**です。

## 座標系

`world-base.svg` の viewBox は `0 0 1000 500`、等距円筒図法相当：

```
x = round((経度 + 180) * 1000 / 360)   # 西経はマイナス、東経はプラス
y = round((90 - 緯度) * 500 / 180)     # 北緯はプラス、南緯はマイナス
```

例：
- (経度 0°, 緯度 0°) ＝ 本初子午線と赤道の交点 → (500, 250)
- (経度 180°, 緯度 90°) ＝ 北極・日付変更線 → (1000, 0)
- (経度 -180°, 緯度 -90°) ＝ 南極・日付変更線 → (0, 500)

## 注意事項

- 座標は中精度SVGのため**±5px 程度の誤差**を許容する
- 国の中心座標は「その国を指す番号マーカー」を置く目的の参考値。形状を厳密に反映していない
- 問題で「○○の位置を地図上から答えよ」とする場合、SVGの輪郭と座標の整合性を必ず目視確認すること
