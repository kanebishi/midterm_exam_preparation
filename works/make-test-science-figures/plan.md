# plan — 理科の図問題対応（make-test 拡張）

## 背景

ユーザーは中学1年理科の中間試験範囲（`subjects/science.md`、試験日 2026-05-19）で小テストを作りたい。試験範囲は植物分野で、教科書（啓林館「未来へひろがるサイエンス」P7〜P9、P13、P20〜P34）に基づく以下の単元：

- 身のまわりの生物の観察
- 植物の特徴と分類
  1. 花のつくり（花のつくりの共通点とちがい、花の変化、マツのなかま、種子で増える植物）
  2. 子葉、葉、根のつくり（単子葉類、双子葉類、葉脈、平行脈、網状脈）
  3. 種子をつくらない植物（シダ植物、コケ植物、胞子のう、胞子、雌株、雄株）
  4. 植物の分類（種子植物：被子植物・裸子植物・双子葉類・単子葉類・合弁花類・離弁花類／種子をつくらない植物：シダ植物・コケ植物）

ユーザーの観察：「テスト内容から言って参照図はかなり必要と思われる」。教科書の問題は実際に花の断面図・葉脈・根・胞子のう等の図と一体で出題されるため、テキストだけだと精度が落ちる。

## 現状の make-test の制約

- `SKILL.md` で「HTML は単体で完結。外部CSS/JSを読み込まない」と規定
- 画像生成ツールは Claude 側にない（PNG/JPG は生成不可）
- 社会向けには既に「インライン SVG 地図 + `<use>` 参照」方式が確立済み（`works/make-test-social-map/`）
- 理科向けの図素材・スキル定義は**現状ゼロ**

## やりたいこと（ユーザー指示）

ユーザーは「先に図素材一式（SVG + SKILL.md 更新）を整備してから、理科テストを生成」する方針（選択肢1）を選択。

## ゴール

1. `make-test` スキルが理科の小テストを生成する際、**インライン SVG の植物模式図を使った問題**を出題できる
2. HTML 1ファイル完結の原則は維持する（外部画像参照しない）
3. 図 SVG は使い回せる形でリポジトリ内に置く（毎回ゼロから描かない）
4. 既存の社会の地図問題対応・他教科（英語・数学）の挙動には一切影響を与えない

## 非ゴール

- 写実的な植物図（教科書も模式図なので十分）
- 動物・実験器具など試験範囲外の図素材（今回の試験範囲は植物のみ）
- 試験範囲外の用語を使った問題

## 次のステップ

→ `spec.md` で具体的な設計（必要な図、SVG 仕様、SKILL.md 追記内容）を提示し、ユーザー確認後に実装着手。
