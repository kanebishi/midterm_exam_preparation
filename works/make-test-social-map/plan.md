# plan — 社会の地図問題対応（make-test 拡張）

## 背景

ユーザーは「中学社会・地理分野」の試験範囲（`subjects/social-studies.md`）で小テストを作りたい。
範囲メモには以下のように、**地図を見ながら答える形式の出題**が明示されている：

- L46〜L50「地図・図表に関する出題」
  - 六大陸・三大洋の位置を地図上で答えさせる
  - 緯線・経線の意味と読み取り
  - 主な国々の位置
- L66「地図から緯度と経度を読む問題」

教師がプリント課題で重視している項目（L52〜L66）にも、国旗や面積順位などテキストで成立する問題に並び、地図ベースの問題が含まれる。

## 現状の make-test の制約

- `SKILL.md` L103 で「HTML は単体で完結。外部CSS/JSを読み込まない」と規定
- 画像生成ツールはClaude側にない（PNG/JPGは生成不可）
- 現状のテンプレ・SKILLには地図系の問題形式が一切定義されていない

## やりたいこと（ユーザー指示 = 「A」）

> 「スキルを改修して、社会だけ"インラインSVG地図入り問題"も生成できるようにする（地図テンプレートを SKILL.md に追加）」

選択肢A/B/Cのうち A を選択。

## ゴール

1. `make-test` スキルが社会の小テストを生成する際、**インライン SVG を埋め込んだ地図問題**を出題できる
2. HTML 1ファイル完結の原則は維持する（外部画像参照しない）
3. ベース地図SVG は使い回せる形でリポジトリ内に置く（毎回ゼロから描かない）
4. 他教科（英語・数学・理科）の挙動には一切影響を与えない

## 非ゴール

- リアルなPNG地図画像の生成（技術的に不可）
- 地図帳（帝国書院）レベルの精密な地図（範囲メモL72で「参考程度」と明記）
- 国旗の描画（テキスト問題で代替可能と判断）
