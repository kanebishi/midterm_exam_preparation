# spec.md — 毎日1枚ドリル運用システム 仕様・設計

最終更新: 2026-06-01

## 設計の中心思想

教材は「器」にすぎない。先に**運用設計**を固め、その器として教材を選ぶ。
本丸の制約は次の2つで、これは教材の質では解けない:

1. 本人が**選択・工夫しなくても回る**こと（冊子を渡すと「どこをやるか」の判断で止まる）
2. 親が見ていない日でも**本人だけで1サイクル完結**すること

次男の特性「監視がないとやらない＋やらなくても大丈夫という楽観」に対する打ち手は2つだけ:

- **バレる確実性を作る**（不確実だとサボる。「たまにチェック」は最悪）
- **やらない損／やる得を"今週"のスパンで本人に接続する**（テスト本番は遠すぎる）

リアルタイム監視（横につく）は卒業し、**非同期の監視**（後で必ず確認される状態）で強制力だけ残す。

## 毎日のサイクル（合意済み）

```
【本人だけで完結】
  ① 親が前夜にセット → "今日のトレイ" に [問題1枚]（解答は親が保持し採点に使用）
  ② 本人が決まった時刻にやる → 別ノートに解答（問題には書き込まない＝周回可能）
  ③ 終わったら "提出トレイ" に置く（＝非同期の証拠。本人は採点しない）
     ※本人の「1日の完了」はここで確定。採点を待たせない＝親不在でも閉じる

【親の事後サポート】不在日は夜・翌日でOK
  ④ 提出トレイを確認（空＝未実施が一目でバレる）
  ⑤ 親が採点（100点満点）→ 点数確定。100点ならポイント付与
  ⑥ 間違えた問題を本人と一緒に直す＋翌日の1枚に再投入
  ⑦ カレンダーに実施マーク

【週次】楽観を崩すエンジン
  ⑧ 1週間の実施日数 → 翌週のSwitch権利時間に連動（持ち越し不可）
     ＋4教科すべて実施でボーナス+60分（満額5時間）
```

### 採点は親が行う運用（2026-06-01 変更：自己採点を廃止）

- **採点は親が事後に行う**（提出トレイ確認時）。本人の自己採点は廃止
- これにより、点数連動ポイントの**自己採点ズル誘因が構造的に消滅**する（最大のリスクが解決）
- 「親不在＝サイクルが閉じない」前回の失敗は再発しない: **本人の1日の完了は「提出トレイに置いた時点」で確定**し、採点を待たせない。採点・点数確定は非同期（夜・翌日でOK）の親レビューに含める
- 暗記の覚え直し（間違い直し）は、親の採点・再出題（⑥）の中で本人と一緒に行う
- 解答シートは本人に渡さず親が保持（peek誘因を断つ＋採点の正確性を担保）

## 提出手段・物理運用（確定 2026-06-01）

- **決めたトレイに置かせる方式**
- 物理2トレイ運用: 「今日のトレイ（未着手）」→ やったら「提出トレイ」へ
- **トレイ設置場所: 本人の勉強机に設置**（毎日の動線上に置き、やる→出すを机で完結）
- **解答シート: 親が保管**（本人には問題のみ渡す。peek誘因を断ち、親採点の正確性を担保）
- **権利時間・ポイントの管理: `reward-sheet.html` を印刷し、親が記載して管理**（採点・記録・翌週権利の計算を1枚で完結）
- 親不在でも夜に確認できる。毎日1枚ずつたまるか否かで未実施が即わかる
- 弱点: 「いつやったか」までは追えない（時刻管理が必要になったら別途検討）

## 動機づけ（確定 2026-06-01）

**週単位のごほうび。「先週の頑張りが翌週に効く／サボった損が翌週に返る」構造で楽観を崩す。採点は親が行う（自己採点は廃止）。**

### 軸① 実施連動「ゲーム権利時間」（継続を報いる）
- 1教科やり切る（1日達成）＝ **60分の権利**が発生（点数は不問。やれば必ず付く）
- **全教科コンプリートボーナス（2026-06-01 追加）**: 1週間で英・数・理・社の**4教科すべてを1回以上実施**したら **+60分（=1日分）の権利**を追加。国語がなく平日が1日余る現状を埋め、かつ「得意教科だけを繰り返す」自己選択方式の抜け道を塞ぐ
- 適用先: **Switch のみ**（ボーナス分も同じ）
- 有効期限: 稼いだ週の**翌週だけ**使える。**持ち越し不可**（ボーナス分も同じ。使い切れなければ消滅）
- → 4教科コンプリートで翌週は最大 **5時間**（4日×60分＋ボーナス60分）のSwitch権利。今週サボれば翌週ゼロ
- **国語導入後の移行**: 週5になったらボーナスを外すだけ。満額=5日分=5時間が変わらず、無改造で移行できる
- 「翌週のみ・持ち越し不可」が設計思想（先週の頑張りが翌週に効く／サボった損が翌週に返る）をそのまま実装

### 軸② 点数連動「ポイント」（質を報いる）
- 親採点で **100点ちょうど → 1pt** 付与（95点等は0pt）
- **1pt = ゲーム時間30分** と交換
- 適用先: **Switch・スマホ どちらでも自由**
- 有効期限: なし。**貯められ、いつでも交換可能**

### 二軸の非対称性（設計の狙い）
| | 軸① 権利時間 | 軸② ポイント |
|---|---|---|
| 報いる対象 | 継続（実施日数） | 質（100点ちょうど） |
| 適用機種 | Switchのみ | Switch・スマホ自由 |
| 期限 | 翌週のみ・持ち越し不可で消滅 | 無期限・貯蓄可 |
| 動機の型 | 「使わなきゃ損」毎週やる短期ドライブ | 「貯めて自由に使う」上位通貨の長期ドライブ |

## 教材ソースの役割分担（2026-05-30 主従を更新）

**方針転換: ベースは購入した問題集。自動生成は「あくまで補足」に格下げ。**

| 種類 | 担当 | 理由 |
|---|---|---|
| **ベース教材（全教科の本丸）** | **購入／手持ちの準拠問題集を1日1ページ。書き込まず別ノートに解いて周回** | 本番に近い図版・配点付きで質が高い。学校配布は書き込み済みで周回不可のため、繰り返せる準拠ワークを別途用意する |
| 補足（穴埋め・周回追加） | make-test 自動生成 | 問題集が尽きた範囲や暗記の追い込みを補助的に供給。メインではない |

- 1日1枚＝**問題集の1ページ**。配点（100点満点想定）で本人が自己採点する
- 問題には書き込まず別ノート運用 → 同じ問題集を何度も周回できる
- make-test は「主役」から「補強用の発行機」に役割縮小

- 補足デジタル（無料）: 啓林館 教科書QRコンテンツ、浜島 e-learningドリル

## 運用モード

- **平常運転モード（今回採用）**: 習慣維持が目的。平日に1教科ローテで1枚（週4日、国語導入後は週5）
- 試験2週間前モード（将来拡張・保留）: 試験範囲に集中。平常運転が定着してから設計する

## リスク（更新: 2026-06-01）

- **点数連動のズル誘因は解消**: 採点を親が行う方式に変更したため、自己採点を盛るリスクはなくなった（2026-06-01変更）
- **代わりに親の採点工数が発生**: ただし提出トレイ確認の事後レビュー（⑤）に含めるため、不在日でも夜・翌日にまとめて処理できる
- **採点が遅れると点数連動ポイントの付与・フィードバックが鈍る**: 親が数日溜めると本人の手応えが薄れる。トレイ確認は最低でも週数回の運用とする
- **権利時間の「持ち越し不可」運用**: 翌週に使い切れなかったSwitch権利は消滅させる。残時間管理（誰がいつリセットするか）を物理運用【iii】で決める必要あり

## 確定事項（2026-05-30 ユーザー回答）

1. **時系列**: 前回中間は終了済み。今回は「次テストに向けた**平常時の習慣システム**」を作る。試験2週間前モードは将来拡張として保留
2. **教科配分（2026-05-31 変更）**: **本人が毎日やりたい教科を1つ選ぶ自己選択方式。曜日固定は廃止**。ただし「1日1教科」の制約は維持（まとめ実施・雑な消化を防ぐ）
3. **1日の分量**: **購入問題集の1ページ＝1枚**。配点（100点満点想定）で本人が自己採点する
4. **教材ベース**: **購入した問題集がベース**。make-test 自動生成は補足扱い（穴埋め・周回追加用）
5. **やる頻度**: **平日のみ**。ただし国語の教材が入るまでは**週4日分**（英・数・理・社を平日4日に1教科ずつ。平日の残り1日は予備＝間違い再出題・復習に充てる）。**国語が入ったら週5へ無改造で拡張**できる構造にする
6. **教材購入**: **4教科すべて文理「中学教科書ワーク」で統一購入**（令和7年改訂版・各1,485円・計約5,940円）。数学・社会も手持ちは書き込み済み＆今後も書き込まれるため周回用に新規購入で確定。詳細は後述「教材の購入リスト」
7. **ごほうび設計（確定 2026-06-01）**: 二軸ハイブリッド。①実施連動の権利時間（1教科=60分・Switch限定・翌週のみ有効・持ち越し不可。**4教科コンプリートで+60分ボーナス→満額5時間**）＋②点数連動ポイント（親採点で100点ちょうど=1pt・1pt=30分・Switch/スマホ自由・貯蓄可）。**採点は親が行う（自己採点は廃止）**
8. **前夜セット担当**: **週末に親が1週間分を一括セット**（毎日の親の手間をゼロにし、不在日でも回る）
