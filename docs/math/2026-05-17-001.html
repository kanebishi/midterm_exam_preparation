問1次の説明は正しいか。正しければ ○、誤っていれば × を書きなさい。正誤
0 は自然数である。
答え: ×（自然数は 1, 2, 3, ... の正の整数。0 は自然数に含まれない）
問2次の数を答えなさい。穴埋め
-5 より 3 大きい数は（）。
答え: -2（数直線で -5 から右へ 3 進む）
問3次のうち整数でないものを選びなさい。選択
  • -7
  • 0
  • +5
  • 0.5
答え: エ. 0.5（整数は正の整数・0・負の整数。小数や分数は整数ではない）
問4|-7| の値として正しいものを選びなさい。選択
  • -7
  • 0
  • 7
  • 14
答え: ウ. 7（絶対値は符号を外した数。常に 0 か正の数になる）
問5絶対値が 4 である数をすべて答えなさい。一問一答
答え: +4 と -4（または 4 と -4。数直線上で 0 からの距離が 4 の点は2つある）
問6次の3つの数を小さい順に並べたとき、2番目に来る数はどれか。選択
-3, +2, -5
  • -5
  • -3
  • +2
答え: イ. -3（小さい順に並べると -5, -3, +2。負の数は絶対値が大きいほど小さい）
問7次の計算をしなさい。一問一答
(-3) + (-5)
答え: -8（同符号の和：絶対値の和 3+5=8 に共通の符号 - をつける）
問8次の計算をしなさい。一問一答
(-7) + (+2)
答え: -5（異符号の和：絶対値の差 7-2=5 に、絶対値の大きい方の符号 - をつける）
問9次の計算をしなさい。一問一答
(+8) + (-3)
答え: +5（または 5。異符号の和：絶対値の差 8-3=5 に、絶対値の大きい方の符号 + をつける）
問10次の計算の答えを書きなさい。穴埋め
(+4) + (+6) = （）
答え: +10（または 10）
問11次の計算をしなさい。一問一答
(-4) - (-7)
答え: +3（または 3。ひく数の符号を変えて加法に直す → (-4) + (+7) = +3）
問12次の計算をしなさい。一問一答
(+3) - (+9)
答え: -6（ひく数の符号を変えて加法に直す → (+3) + (-9) = -6）
問13次の計算をしなさい。答えとして正しいものを選びなさい。選択
(-3) + (+5) - (-2)
  • -6
  • 0
  • +4
  • -4
答え: ウ. +4（項を並べた式に直すと -3 + 5 + 2 = 4）
問14次の式を、項だけを並べた式に直しなさい。穴埋め
(+4) - (+7) + (-3) = （）
答え: 4 - 7 - 3（計算すると -6。+(+) → +、-(+) → -、+(-) → - のルールで符号を整理する）
